# ADR-0003：采用配置驱动的NPC体验引擎

- 状态：Accepted
- 日期：2026-08-01

## 背景

首页是一座美式西部酒吧，用户点击老板、酒保、探险者等NPC进入不同内容。若NPC组件直接包含业务规则，未来替换人物、增加场景、做移动降级或直接URL都会复制逻辑。

## 决策

- 首版使用2.5D分层插画，不使用全3D自由场景。
- 场景、NPC、热点、出口和对话采用经过模式校验的版本化配置。
- NPC只能触发能力注册表中的白名单动作。
- 授权和业务规则由应用服务在服务端执行。
- 所有功能有独立URL和标准导航。
- 首版只实现门外与大厅，但模型支持多场景。
- 对话首版完全确定性；AI只作为未来可替换适配器。

## 后果

正面：

- 场景、美术和功能可以独立演进。
- 对话路径、死节点和功能动作可自动测试。
- 支持移动、无障碍和静态降级。

代价：

- 需要维护配置模式、能力注册表和兼容版本。
- 设计者不能在配置中加入任意脚本。
- 场景体验必须遵守严格资源预算。
