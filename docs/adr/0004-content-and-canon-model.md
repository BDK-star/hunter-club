# ADR-0004：采用来源感知的双内容模型

- 状态：Accepted
- 日期：2026-08-01

## 背景

角色、念能力和组织不是普通帖子；同时，考据和分析也不能被压缩为百科字段。漫画、1999动画、2011动画和其他材料可能存在差异，混合展示会制造事实污染和剧透泄漏。

## 决策

- 结构化资料实体和专题文章均为一等内容。
- 首版资料类型为角色、念能力、组织和篇章。
- 漫画是主线正典，但保留其他来源的差异记录。
- 关键事实和实体关系带来源引用、正典状态、剧透等级和核对时间。
- 已发布内容使用不可变修订、审核与可回退指针。
- 用户维护建议通过投稿和审核进入正式内容。

## 后果

正面：

- 可构建可靠搜索、关系探索和来源对照。
- 剧透过滤能在查询层执行。
- 编辑争议可以定位到具体事实与来源。

代价：

- 数据录入和审核比普通文章复杂。
- 需要设计事实声明、来源和修订的管理界面。
- 内容迁移必须保留来源和版本历史。
